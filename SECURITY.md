# Security Policy

NovusWarden takes security seriously. If you believe you have found a security vulnerability in our application, please report it responsibly so we can resolve it promptly.

## Reporting a Vulnerability

- **GitHub Private Vulnerability Reporting (Preferred):**  
  Submit a confidential advisory directly at [GitHub Security Advisories](https://github.com/SGC-NOVUS/novuswarden/security/advisories/new).
- **Direct Email:**  
  You can contact the maintainer directly at: `support@sgc-novus.fun`.

Please do not open public issues or public discussion threads for suspected security vulnerabilities before they have been triaged and addressed.

## Scope

- Vulnerabilities in the NovusWarden server code (`SGC-NOVUS/novuswarden`).
- Issues in official upstream Bitwarden client applications (mobile, desktop, browser extensions) should be reported to [Bitwarden](https://github.com/bitwarden).
- If a bug is confirmed to originate in upstream Vaultwarden, we will coordinate responsible disclosure with the upstream maintainers.

## Guidelines

- Give us reasonable time to investigate and release a fix before public disclosure.
- Make a good faith effort to avoid data destruction, service disruption, or privacy violations.
