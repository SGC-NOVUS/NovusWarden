Place custom branded web-vault assets in this folder.

Any files here are copied into /web-vault during image build.
Use the same relative paths as upstream web-vault assets.

Examples:
- novus-brand.css
- images/icons/icon-192x192.png
- images/logo.svg
- images/logo-white.svg
- images/logo-dark@2x.png
- images/register-layout/logo-horizontal-white.svg
- images/register-layout/logo-horizontal-white.png
- favicon.ico
